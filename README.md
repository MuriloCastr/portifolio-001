# Murilo Castr — Digital designer & builder

Portfólio pessoal com uma direção visual editorial, interface responsiva e microinterações construídas em HTML, CSS e JavaScript puro.

## O que tem aqui

- Hero interativo com visual 3D em CSS
- Cursor luminoso, tilt 3D e botões magnéticos
- Animações de entrada por scroll e marquee infinito
- Layout responsivo para celular, tablet e desktop
- Respeito a `prefers-reduced-motion`
- Sem framework, bundler ou dependências de build

## Como executar

Abra o `index.html` no navegador ou sirva a pasta com qualquer servidor estático.

## Publicação

Este projeto foi preparado para o repositório `MuriloCastr/portifolio-001` e para publicação via GitHub Pages.
